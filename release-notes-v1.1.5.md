# HTC Weather Sky Live Wallpaper v1.1.5

**versionCode:** 106  
**versionName:** `1.1.5-aspect-crop-gl`  
**Package:** `com.htc.android.wallpaper.weather`

## Highlights

- **Open-Meteo weather** built in — no HTC Weather app or flip clock required for sky updates.
- **Manual city search** with list picker, status line, and toasts.
- **Full-screen sky video** with **OpenGL center-crop** (fixes vertical stretch on some Samsung devices).
- **High refresh rate** hint when the wallpaper is visible.

## Requirements

1. Install this APK (**HTC Weather Sky** live wallpaper).
2. Install the **video companion** package `com.htc.htcweatherassets` (HTC sky MP4 resources). See README *Video companion* section.

## Install

1. Download `HTC-Weather-Sky-LiveWallpaper.apk` from this release.
2. Install (allow unknown apps if prompted).
3. Install video companion if you have not already.
4. **Wallpapers → Live wallpapers → HTC Weather Sky**.
5. Open **gear / Weather Sky location** to set automatic GPS or manual city.

## Signing

Debug-signed for sideloading (not Play Store).
