# HTC Weather Sky v1.2.0 — bundled sky video

**versionCode:** 107  
**versionName:** `1.2.0-bundled-sky-video`  
**Package:** `com.htc.android.wallpaper.weather`

## Highlights

- **Single APK (~146 MB)** — all 36 HTC sky MP4 loops are **inside** the live wallpaper app.
- **No separate install** of `com.htc.htcweatherassets` required on v1.2.0+.
- Open-Meteo weather, manual city picker, OpenGL center-crop video (from v1.1.5), high refresh hint.

## Install

1. Download **`HTC-Weather-Sky-LiveWallpaper.apk`** from this release (large file — Wi‑Fi recommended).
2. Install and set **HTC Weather Sky** as your live wallpaper.
3. Open **Weather Sky location** (gear) for GPS or manual city.

You may uninstall the old **HTC Weather Video / htcweatherassets** companion if you only used it for this wallpaper.

## Upgrade from v1.1.x

Install over the previous Weather Sky APK. Re-select the wallpaper if the sky does not update.

## Signing

Debug-signed for sideloading.
